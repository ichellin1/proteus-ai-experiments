# Proteus AI Experiments

Experiments in connecting LLMs and agents to [Proteus](https://github.com/ichellin1/proteus).

These are experiments, not releases: nothing here is published to crates.io or npm. Each one is
shown by its code and by a recording of it running.

## Experiments

Each experiment lives in its own folder.

| Experiment | Status |
| --- | --- |
| An MCP server that lets an agent see and drive a running Proteus app | Planned |
| A generative UI, where an agent's answer is a transformation of what's on screen, with evals | Planned |

## Proteus

The experiments use Proteus's published releases:
[`proteus-sdk`](https://crates.io/crates/proteus-sdk) on crates.io and
[`proteus-sdk`](https://www.npmjs.com/package/proteus-sdk) on npm.
